    What is behind the numbers

    Every change re-sizes a complete pump for the duty: the impeller diameter is solved so the rated head is met, the inlet blade angle is set from the real flow angle (leakage and blade blockage included), and the volute throat is sized so the rated flow sits at the best efficiency point.

    Head comes from Euler's equation with Wiesner slip, minus incidence, channel friction, volute and discharge-cone losses. Wear-ring leakage, disk friction (Daily–Nece) and a bearing and seal allowance set the power. Friction losses are scaled once so the hydraulic efficiency matches published statistics for pumps of this size and specific speed (Gülich, Centrifugal Pumps), and that scale is then held fixed.

    This is a 1D estimate. Expect roughly 10–20% error on absolute head and efficiency against a real pump, and trust trends between designs more than the absolute values. The API 610 items are screening checks, not compliance. Source, tests and the full study: github.com/dmarkentell/pump-design.
